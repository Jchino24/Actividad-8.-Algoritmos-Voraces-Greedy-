# Actividad 8 - Algoritmos Voraces (Greedy)

Este repositorio contiene las soluciones en Java para dos problemas clásicos de optimización utilizando estrategias Greedy:
1. **Mochila Fraccional:** Maximización de valor permitiendo fraccionar objetos.
2. **Cobertura de Antenas:** Minimización de antenas instaladas para cubrir un conjunto de puntos.

## Cómo ejecutar el proyecto

1. Clona este repositorio:
   `git clone <https://github.com/Jchino24/Actividad-8.-Algoritmos-Voraces-Greedy-.git>`
2. Navega al directorio del proyecto.
3. Compila los archivos Java:
   `javac MochilaFraccional.java`
   `javac CoberturaAntenas.java`
4. Ejecuta los programas:
   `java MochilaFraccional`
   `java CoberturaAntenas`
